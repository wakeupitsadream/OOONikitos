## 4. Что делает Максим (техническое)

1. Перевести репо `wakeupitsadream/OOONikitos` в private (Settings → Danger Zone → Change visibility).
2. Vercel: проект `belye-niti` уже создан и привязан к репо (production = `main`, preview для остальных веток). После первого пуша кода проверить Framework Preset = Next.js. Добавить в Project → Domains дополнительные адреса `dezgarant56.vercel.app` и `brilliant-remont56.vercel.app` (если свободны; иначе любые свободные — и вписать их в `config/sites.ts`).
3. Яндекс.Метрика: создать три счётчика (по одному на сайт), указать vercel.app-хост и будущий домен; ID → env `NEXT_PUBLIC_YM_BELYE_NITI`, `NEXT_PUBLIC_YM_DEZGARANT`, `NEXT_PUBLIC_YM_REMONT`.
4. Telegram: создать бота в @BotFather → `TELEGRAM_BOT_TOKEN`; владелец пишет боту любое сообщение, chat_id берётся из `https://api.telegram.org/bot<TOKEN>/getUpdates` (или через @userinfobot) → `TELEGRAM_CHAT_ID` (и при желании `TELEGRAM_CHAT_ID_DEZGARANT`, `TELEGRAM_CHAT_ID_REMONT`, `TELEGRAM_CHAT_ID_BELYE_NITI`).
5. SMTP для email-дублей: почтовый ящик владельца (Яндекс 360 / Mail.ru) с паролем приложения → `SMTP_HOST`, `SMTP_PORT`, `SMTP_USER`, `SMTP_PASS`, `LEAD_EMAIL_FROM`, `LEAD_EMAIL_TO_<SITE>`.
6. Env в Vercel (Production + Preview): все ключи из п. 3–5, плюс `NEXT_PUBLIC_URL_<SITE>` (пока vercel.app-хосты), `NEXT_PUBLIC_YANDEX_VERIFICATION_<SITE>` (после добавления сайтов в Яндекс.Вебмастер), `LEAD_DRY_RUN=1` только для Preview.
7. С российского IP открыть `https://fp.rospotrebnadzor.ru/licen/?record_uuid=79d1374a-5a63-11f1-9a50-40f2e9218cba` и подтвердить, что это карточка ООО «Белые Нити»; проверить, есть ли компания в списке на `56.rospotrebnadzor.ru/spisok-dezinsekcziej-na-territorii-orenburgskoj-oblasti`.
8. Секреты — только в Vercel Dashboard. Ключ, попавший в чат или репо, считается скомпрометированным и перевыпускается.

## 6. Что скрыто до ответа владельца (после ревью 14.09.2026)

Правило проекта: обещание, которое владелец не подтвердил, на сайт не выходит. Ниже — что именно
убрано или помечено «уточняется» и одной правкой возвращается после ответа.

| Что | Где сейчас | Как вернуть |
|---|---|---|
| Срок гарантии в днях (90 / 45 / 30) | показывается с пометкой «уточняется» | `content/dezgarant/prices.ts`: `GUARANTEE_STATUS = 'confirmed'`, при необходимости поправить `guaranteeDays` и `DEFAULT_GUARANTEE_DAYS` |
| «Машина без надписей, специалист без формы» | заменено на «согласуем порядок приезда» | `content/dezgarant/faq.ts` (ответ про соседей), `content/dezgarant/services.ts` (клопы, после смерти), карточка Stat на главной ДезГаранта |
| Города области с выездом | список пуст, плашки не рендерятся | `content/dezgarant/faq.ts` → `AREA_CITIES` |
| «Доплат за степень заражения не бывает» | заменено на «цена меняется только вместе с объёмом» | при подтверждении можно вернуть жёсткую формулировку в `faq.ts`, `ceny/page.tsx`, `DezDiagnostic.tsx` |
| Экономия абонемента против разовых выездов в ₽ | заменена на качественную фразу | `components/blocks/B2bCalculator.tsx`, коэффициент `ONE_OFF_PREMIUM` в `lib/calc/b2b.ts` |
| Образцы договора, акта и журнала «пришлём по запросу» | «обсудим на обследовании» | `app/%5Fsites/dezgarant/biznesu/page.tsx` — после получения PDF |
| Норма выработки и паузы на сушку (Ремонт) | с пометкой «уточняется» | `content/remont/prices.ts` → `status: 'confirmed'` у ставок |

Аналитика: Вебвизор Метрики включён (`components/layout/Metrika.tsx`), политика об этом говорит,
форма заявки помечена `ym-hide-content ym-disable-keys` — ввод имени и телефона в запись не попадает.

Заявки, заполненные быстрее 3 секунд, больше не отбрасываются: они доставляются с пометкой
«возможно, автозаполнение или бот». Отбрасывается только заявка с заполненной скрытой ловушкой,
и такой случай пишется в лог функции.
