# ООО «Белые Нити» — сайты

Зонтичный сайт ООО «Белые Нити» (Оренбург) и два брендовых сайта: «ДезГарант» (дезинфекция, дезинсекция, дератизация — лицензия Роспотребнадзора) и «Бриллиант Ремонт» (штукатурка и отделка). Один Next.js-проект, один Vercel-проект, три хоста.

- План сборки: `docs/PLAN.md`
- Правила проекта для сборочной сессии: `CLAUDE.md`
- Входные данные и незакрытые вопросы владельцу: `docs/CONTENT-INPUTS.md`
- Исходники бренда: `docs/brand/`
- Результаты разведки: `docs/research/`

Код появится в ветке `claude/belye-niti-websites-w42jwl`; production — ветка `main` (деплой Vercel).
